Process Model

Status: PAUSED Release: development

Task Planning model for adaptive, executable, team-based clinical workflows. Includes the TP-VML visual notation for designing care plans, a decision rule language, and real-world clinical process examples.

Figure 1. Specification Component Overview

Specifications

  • CDS, Guidelines and Planning Overview PAUSED — Overview of CDS, Guidelines, and Planning specifications. — Positions Task Planning, Decision Language, and GDL within the openEHR platform

  • Task Planning (TP) Specification PAUSED — An adaptive, executable, team-based model of clinical workflow — Adaptive, executable model for team-based clinical workflow and care plans

  • Decision Language specification PAUSED — Rule language for use with GDL, TP. — Rule language for encoding clinical conditions in guidelines and workflows

  • Task Planning Visual Modelling Language (TP-VML) PAUSED — A visual modelling language for clinical plans and workflows. — Visual notation for designing and communicating clinical care plans

  • openEHR CDS, Guidelines and Planning Examples PAUSED — Real-world CDS/Process examples. — Worked examples of care pathway and guideline artefacts
