BASE Release 1.3.0 (unreleased)

1.3.4

Define the TEMPLATE_ID identifier: the human-readable identifier (HRID) form is strongly recommended and, when used, is the modern (ADL 2) form carrying a mandatory namespace; a legacy free-text name remains permitted but is deprecated. Adds is_hrid(), HRID segment/version accessors and a Template Identifiers section (SPECBASE-42, SPECPR-124).

S Iancu

10 Oct 2026

1.3.3

Redefine ARCHETYPE_ID as an exact archetype identifier rather than an identifier-or-reference: value is now the grammar-validated Hrid primitive, its version carries the three-part semantic version, and namespace, major_version, minor_version and patch_version accessors are added. The Syntaxes section defers the shared identifier grammar to the {openehr_base_artefact_identification}[Artefact Identification^] specification (SPECBASE-35, SPECBASE-49, SPECBASE-50, SPECPR-363).
