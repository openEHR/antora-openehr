Foundation Types STABLE

Primitive and structured types assumed by all openEHR specifications: Boolean, Integer, Real, String, Date, Time, DateTime, Duration, and generic containers such as List, Set, and Interval. These types are not openEHR-specific inventions but rather a formal specification of the primitive types assumed to exist in any host programming environment. BMM schemas and all other openEHR models reference foundation types as their leaf-level value types.

Purpose

This document describes the openEHR Foundation Types, a collection of built-in and library types whose semantics are assumed by all other openEHR specifications.

The intended audience includes:

  • Standards bodies producing health informatics standards;

  • Research groups using openEHR, ISO 13606, archetypes and related technologies;

  • The open source healthcare community;

  • Solution vendors.
