Conformance Specifications

Status: DEVELOPMENT Release: development

Framework for certifying openEHR platform implementations. Defines conformance profiles, test cases per REST API endpoint, and a certificate scheme for verifying vendor compliance against the openEHR specifications.

Figure 1. Specification Component Overview

Specifications

  • openEHR Conformance Guide DEVELOPMENT — Guide to conformance testing in openEHR. — Introduction to the openEHR conformance testing approach and certification process

  • openEHR Platform Conformance Test Schedule DEVELOPMENT — System Under Test (SUT), Test, Conformance Schedule, Profiles, Certification — Test cases per REST API endpoint for verifying platform implementation compliance

  • openEHR Platform Profiles DEVELOPMENT — Platform component profiles. — Conformance profiles grouping capabilities into tiers for partial compliance claims

  • openEHR Conformance Certificate DEVELOPMENT — openEHR Conformance Certificate. — Certificate scheme for documenting and publishing verified platform conformance
