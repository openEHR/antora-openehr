Common Information Model STABLE

Cross-cutting Reference Model constructs: the archetyped class hierarchy, entry metadata, feeder audit for legacy data, party references, change control, version containers, and directory structures. The LOCATABLE class and its archetyped subclass form the root of the constraint hierarchy that archetypes act upon, making this package central to understanding how archetypes bind to RM instances. The VERSIONED_OBJECT and VERSION classes implement an optimistic locking model for EHR content, supporting concurrent access and merge scenarios.

Purpose

This document describes the architecture of the openEHR Common Reference Model, which contains patterns used by other openEHR reference models.

The intended audience includes:

  • Standards bodies producing health informatics standards;

  • Academic groups using openEHR;

  • The open source healthcare community;

  • Solution vendors;

  • Medical informaticians and clinicians interested in health information.

  • Health data managers.
