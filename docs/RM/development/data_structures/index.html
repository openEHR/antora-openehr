Data Structures Information Model STABLE

Generic structural types used throughout the Reference Model: single items, lists, tables, and trees, each parameterised to hold any RM data type instance. ITEM_TREE, ITEM_LIST, ITEM_TABLE, and ITEM_SINGLE are the four structural types, parameterised with ELEMENT as the leaf value holder. Archetypes impose specific structural constraints on these types to define the shape of data captured in clinical entries.

Purpose

This document describes the common data structures used in openEHR reference model, including lists, tables, trees, and history.

The intended audience includes:

  • Standards bodies producing health informatics standards;

  • Academic groups using openEHR;

  • The open source healthcare community;

  • Solution vendors;

  • Medical informaticians and clinicians interested in health information.

  • Health data managers.
